# 语音识别自定义纠正词典（示例）
#
# 用法：
#   1. 把本文件拷到 ~/.linux-voice-input/corrections.txt
#   2. 在 ~/.linux-voice-input/config.yaml 里开启 corrections.enabled: true
#   3. 按需增删下面的规则，保存即生效（无需重启，程序会在下一次识别时自动重载）
#
# 格式（每行一条规则）：
#   正确词 = 错词1, 错词2, ...
#   - '=' 左边是你想要的最终结果，右边是识别时可能出现的错误写法
#   - 多个错词用逗号分隔，中文逗号“，”和英文逗号“,”都可以
#   - 以 '#' 开头的行是注释，空行会被忽略
#
# 匹配规则：
#   - 纯文本替换，从左到右扫描，优先匹配最长的错词
#   - 已替换出的正确词不会被后续规则再次替换（不会连锁触发）
#
# ⚠️ 重要提醒 —— 避免误伤：
#   替换是无脑的文本匹配，如果一个“错词”在日常语境里也是正常词，就可能改错。
#   例如把「现成」全部改成「线程」，那么“现成的方案”会被误改成“线程的方案”。
#   降低误伤的建议：
#     - 首选那些日常几乎不会单独出现的词，尤其是英文术语的音译（最安全）
#     - 对有歧义的同音词，尽量用更长的上下文，比如用「多现成」而不是「现成」
#     - 拿不准的规则先小范围试用，发现误伤就删掉或改长
