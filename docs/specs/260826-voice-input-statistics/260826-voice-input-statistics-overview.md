# 语音输入本地统计功能

## Summary

- 新增默认关闭的 `statistics.enabled` 配置和托盘开关；关闭只暂停新增，历史数据保留。
- 只统计成功粘贴到目标窗口的输入；取消、过短、空结果、识别失败、粘贴失败和 `--test` 不计入。
- 数据按本地自然日保存到 `~/.linux-voice-input/stats/YYYY/MM/DD.json`，日文件是唯一数据源，不维护第二份总计。
- 统计日文件不保存识别文本、纠错后文本或逐次事件；托盘和 CLI 通过合并日文件展示今日、最近 7/30 天、指定月份及累计数据，现有运行日志行为不在本功能范围内。
- 只沉淀客观耗时，不配置传统打字速度，也不计算节省时间，供后续分析工具直接使用。

## 数据结构与统计口径

每个日文件使用 `version: 1`，包含 `date`、`updated_at`、当日 `totals` 和按识别引擎划分的 `engines`。每个统计桶包含：

- `successful_inputs`：成功执行 `Ctrl+V` 的输入次数。
- `characters`：排除 Unicode 空白后的 rune 数，标点和 emoji 也计入。
- `han_characters`：其中属于 Unicode Han 字符集的汉字数。
- `recording_duration_ms`：开始录音至用户停止录音的累计毫秒数。
- `input_duration_ms`：开始录音至文字实际注入窗口的累计毫秒数；包含识别和纠错，不包含后续剪贴板恢复等待。
- `corrected_inputs`：最终文本与原始识别文本不同的输入次数。
- `correction_edits`：纠错前后文本的 rune 级 Levenshtein 最小编辑数。
- `correction_strategy_inputs`：各内置纠错策略实际产生修改的输入次数。

文字成功注入时的本地日期决定文件路径。每日文件永久保留，不自动清理；年月目录避免单目录和单文件无限增长，也方便按月归档或删除。

## 实现方案

- `stats` 包负责文本指标数值化、日聚合、范围合并、异步单写入器和人类可读格式化。进入异步队列的 `Event` 已不含任何用户文本。
- 每次成功输入只更新当天的内存文档并调度一次后台写入。写入使用同目录临时文件、`0600` 权限、`fsync` 和原子重命名；失败保留 dirty 状态供下一次事件或关闭时重试，且不影响输入流程。
- 损坏或不支持版本的日文件不会被覆盖；托盘和 CLI 返回明确错误。正常关闭会刷新队列，确保独立录音进程和守护进程不丢最后一次成功输入。
- `session.Controller` 在录音开始时固定实际识别引擎，在停止动作发生时记录纯录音时长；`input.PasteText` 返回 `InsertedAt`，该时间在 `Ctrl+V` 成功后、800ms 剪贴板恢复等待前采集。
- 托盘提供“启用语音统计”和“查看语音统计”，后者展示今日及最近 30 天。CLI 提供：

  ```text
  --stats
  --stats --days N
  --stats --month YYYY-MM
  ```

  默认输出今日、最近 7 天、最近 30 天、全部累计以及按引擎汇总。

## 测试计划

- 覆盖 Unicode 字符/汉字计数、rune 编辑距离、策略去重、时长累计和按引擎聚合。
- 覆盖跨日写入、最近 N 天、指定月份、全部累计、关闭/重开、首次创建和正常关闭刷新。
- 覆盖损坏文件不覆盖、无关 JSON 文件忽略、配置默认关闭和旧配置兼容。
- 覆盖托盘开关持久化、配置重载、展示格式、CLI 参数解析与范围输出。
- 运行完整 `go test ./...`、关键包 `go test -race` 和 `go vet ./...`。

## Assumptions

- “纠错”只指现有模型与用户词典的自动纠错，不监听用户粘贴后的人工修改。
- 统计文件只提供匿名日汇总，无法还原单次输入内容或逐次时间线。
- 第一版不提供自动清理、重置、打字速度基准或时间收益计算。
